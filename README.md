# GACD Run 42.2
Marathon (42.2 km) training tracker PWA for 2027. Live: https://alesilee119.github.io/marathon-2027/
iPhone: open in Safari → Share → Add to Home Screen. Connect Strava in Settings (create an API app at https://www.strava.com/settings/api, Authorization Callback Domain `alesilee119.github.io`). Keys and data are stored only in your browser.
